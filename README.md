# E-commerce_demand_analysis
# E-Commerce Revenue Intelligence & Demand Risk Analysis

**Sector:** Retail E-Commerce  
**Tools:** Python, Pandas, Matplotlib, Seaborn  
**Dataset:** Multi-year transactional data (2012–2015)

## What this project covers
- Revenue growth analysis across 3 years and 4 product launches
- 5 patterns and anomalies identified from the data
- Channel quality comparison (paid vs organic)
- Cross-sell revenue sizing and A/B test strategy

## Files
| File | Description |
|------|-------------|
| `ecommerce_demand_analysis.ipynb` | Main analysis notebook |
| `maven_combined.csv` | Raw dataset |

## Key Findings
1. August–September refund spike in Mr. Fuzzy (10%+) — recurring seasonal anomaly
2. Hudson River Mini Bear gets 88% of revenue from cross-sell placement
3. Valentine's Day drives +65% uplift for Forever Love Bear with no dedicated campaign
4. Organic/direct customers have the highest order value and lowest refund rate
